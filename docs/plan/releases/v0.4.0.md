# Proccoli 0.4.0

*Released 2026-11-24* as tag `v0.4.0` (commit `a2eab5a`).

Charts are honest about time: changing the Graph Time Range or Update Interval regroups or refills the graphs instead of stretching old points, and the time Proccoli wasn't running is shaded, with a hover saying how long. Adds SECURITY.md.

## Release notes

As published on GitHub:

Charts that are honest about time.

- Changing the Graph Time Range or Update Interval redraws the charts for the new range, instead of stretching what they held
- The time Proccoli wasn't running is shaded on the charts; hover over it to see how long
