# Proccoli 0.1.0

*Released 2026-11-23* as tag `v0.1.0` (commit `f52b1cc`).

The first release: the window with a page per device (processor, memory, drives, network, GPU, battery), processes and apps, the administrator helper, Preferences and packaging; then styles, palettes, sidebar graphs and per-entry sidebar settings, the rename to Proccoli and its logo; and the Overview page, the stall watchdog, back and forward, Go To, and a collapsible sidebar.

## Features

None tracked as features yet (features began with v0.3.0).

## Bugs fixed

None tracked as bugs yet.
