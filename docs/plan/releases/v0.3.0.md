# Proccoli 0.3.0

*Released 2026-11-24* as tag `v0.3.0` (commit `a21b7d6`).

The metrics history in SQLite, with Export Statistics and graphs filled from it at start-up; one chart family everywhere, with value axes in your units and hover on every chart; the Intel Details tab on the shared charts; the logo is the main menu; Update Interval replaces Refresh Speed; Lightweight Mode; Switch To any running app.
