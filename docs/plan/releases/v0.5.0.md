# Proccoli 0.5.0

*Released 2026-11-25* as tag `v0.5.0` (commit `02a83f0`).

The history is recorded in the background by `proccoli`, a user service that serves every reading over D-Bus, and the window (`proccoli-gui`) only shows them; the two install separately. Honest GPU readings on AMD APUs and AMD detailed statistics; a graph toolbar; custom time ranges; exports describe their devices; Lightweight Mode draws with Cairo; 18 more styles.

## Release notes

As published on GitHub:

More styles and palettes, and new program names.

### New names
- The recorder is now **`proccoli`** (program, systemd user unit `proccoli.service`, package), and the window is **`proccoli-gui`**.
- Installing `proccoli-gui` brings `proccoli` with it; the old `proccoli-metrics` package is removed on upgrade, and your history and settings carry over.
- Logs: the window's is `~/.local/state/proccoli/proccoli-gui.log`, the recorder's `proccoli.log`.

### Appearance
- 18 more styles: light (Mint, Rose, Lavender, Paper, Solarized Light, Gruvbox Light, Catppuccin Latte, High Contrast Light) and dark (Nord, Dracula, Gruvbox Dark, Solarized Dark, Catppuccin Mocha, Tokyo Night, Forest, Ember, Black, High Contrast Dark). Text is at least 7:1 contrast on every surface.
- 13 more chart palettes, five of them made to stay distinguishable with color blindness (Okabe–Ito, Tol Bright, Tol Vibrant, Tol Muted, Viridis), plus Tableau 10, Matplotlib, ColorBrewer Set 1 and Dark 2, Catppuccin, Gruvbox, One and Tokyo Night.
- In Lightweight Mode, Preferences marks the settings it fixes with a padlock and says so at the top of the page.

### Fixes
- The Overview's tables no longer change width as the busiest apps change.
- After *Restart Now*, the window keeps its name in process lists instead of showing as `python3`.
- Running the test suite can no longer start a stray recorder.

### Install
```sh
sudo apt install ./proccoli_0.5.0_all.deb ./proccoli-gui_0.5.0_all.deb
```
