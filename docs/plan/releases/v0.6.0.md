# Proccoli 0.6.0

*Released 2026-11-28* as tag `v0.6.0`.

Sidebar groups for GPUs, drives, network and batteries; a graph type per
sidebar entry; Preferences in six pages; recording from boot; a window
that stays quick when processes come and go; and steadier graphs.

## Release notes

Sidebar groups, a graph type per entry, and a steadier window.

### New
- **Sidebar groups:** GPUs, Drives, Network and Batteries each have a group entry with their devices beneath it. The group's page compares its devices side by side; Network and Drives show their total speed. Click a group's arrow to hide or show its devices.
- **Graph Type per entry:** *Meter Type* is now *Graph Type*, and each sidebar entry can have its own (Preferences → Sidebar → the entry).
- **Preferences in six pages:** Appearance, Sidebar, Tables, Recording, Devices and System.
- **Recording from boot:** Proccoli offers once to keep recording from boot, before you log in (Preferences → Recording → *Start at Boot*).
- **Shortcuts:** F2 opens Preferences and F1 the Keyboard Shortcuts; Ctrl+, and Ctrl+? still work.
- **A shorter README** with screenshots, and the full [user guide](https://github.com/mamadingleberry/proccoli/blob/main/docs/USER-GUIDE.md).

### Fixed
- The window no longer slows down and freezes when many processes come and go (for example a container restarting all night), and the process tables pause while the screen is locked.
- Changing the Time Range no longer shades the last seconds as "Proccoli wasn't running".
- An NVIDIA GPU too new for the system's PCI database is named by its driver (e.g. "NVIDIA GeForce RTX 5060 Laptop GPU"), not "NVIDIA GPU".
- Graphs filled from the history no longer miss a point every few minutes, and the update ticks no longer drift.
- An idle Intel GPU's Overview card shows its idle state instead of a blank chart; a chart with no readings says "No data".
- Only one recorder runs per user, and a recorder stopped by a signal is started again.
- The recorder now logs its own stalls and crashes, like the window.

### Install
```sh
sudo apt install ./proccoli_0.6.0_all.deb ./proccoli-gui_0.6.0_all.deb
```
